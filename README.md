# 艦これ遠征サポート v5.8.1

## v5.8.1 修正

通常遠征まで「済」となり選択できない不具合を修正。旧履歴の移行をマンスリーに限定し、混入済みの実施済みデータも端末・クラウド読込時に補正します。帰投履歴と正しいマンスリー記録は保持します。

## v5.8 改善

- 初回読込失敗後の同期復旧、未同期変更の再送・再読込後の復旧、実際の通信結果と最終成功時刻の表示。
- 検索を先頭へ移動。お気に入りは3件＋展開、並べ替えモード、交戦リスク表示。
- 一覧から詳細へ移動し、戻ると検索条件とスクロール位置を復元。タグ・時給は任意表示。
- おすすめは上位3件＋展開。報酬／前提込み時間効率／損傷回避、前提記録済みのみ、前提ルートを含むII型除外。
- 開放ルートの2個前を直接の前提ごとに表示。通知設定に5分間隔の配信と遅延の目安を明記。

検証と制約は [RELEASE_V5.8.md](RELEASE_V5.8.md) を参照。

## 野埼タイマー

タイマータブで「野埼」を選ぶと母港給糧艦システム向けタイマーを使えます。

- 野埼：45分を自動設定（15分ごと cond +2、cond54までの目安）
- 野埼改：30分を自動設定（15分ごと cond +3、cond54までの目安）
- 改装状態を選ぶだけで時間を自動設定
- 端末通知ON/OFF
- ローカル保存・クラウドスナップショット同期対応

ゲーム側では編成変更や、15分以上経過後に母港へ戻って給糧判定が行われるとタイマーがリセットされるため、アプリ側では必要に応じて「リセット」を押してください。
