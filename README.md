# 艦これ遠征サポート v5.0

遠征タイマー、遠征詳細、資源記録、通知、プリセットをまとめたPWAです。

## v5.0 UI再編

- iOS純正アプリを意識した白・薄灰色中心のミニマルUIへ刷新
- ナビゲーションを「ホーム / 遠征 / タイマー / 記録 / 設定」に再編
- 「攻略」は遠征タブ内の「おすすめ・マンスリー」に統合
- ホームは帰投チェック、遠征状況、今日の獲得資材、所持資源、クイックプリセットに集中
- 通信時間やサーバー時刻差などの技術情報は通常画面から外し、診断画面へ移動
- ダークモードもiOS系の高コントラスト配色へ更新

## 野埼タイマー

タイマータブで「野埼」を選ぶと母港給糧艦システム向けタイマーを使えます。

- 野埼：45分を自動設定（15分ごと cond +2、cond54までの目安）
- 野埼改：30分を自動設定（15分ごと cond +3、cond54までの目安）
- 改装状態を選ぶだけで時間を自動設定
- 端末通知ON/OFF
- ローカル保存・クラウドスナップショット同期対応

ゲーム側では編成変更や、15分以上経過後に母港へ戻って給糧判定が行われるとタイマーがリセットされるため、アプリ側では必要に応じて「リセット」を押してください。
