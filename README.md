# 艦これ遠征サポート v4.6

遠征タイマー、遠征検索、資源記録、通知をまとめて扱うPWAです。

## v4.6 前提遠征リンク・お気に入り選択改善

- 遠征詳細に「前提遠征・開放条件」を追加。前提遠征は詳細へワンタップで移動できます。
- 毎月前提がある遠征は「今月済 / 今月未記録」を表示します。
- 艦隊カードの遠征ドロップダウン最上部に「★ お気に入り」を追加し、スマホでも素早く選べるようにしました。
- ダークモードの遠征カード・お気に入り・詳細周りの文字色を追加調整しました。

## v4.2の変更点

- 遠征詳細の「編成条件・編成例」をカード化
- 各遠征の編成文字列からパターン別の編成条件と編成例を表示
- 43: ミ船団護衛(二号船団) は、護衛空母ルート / 軽空母ルートを明示
- ダークモードで文字が黒く沈む問題を追加修正
- モバイル下タブ、クイックプリセット、艦隊カード、遠征詳細、入力欄のコントラストを改善

## 更新手順

既存リポジトリに中身を上書きしてから、以下を実行してください。

```bash
npm install
npm run build
git status
git add .
git commit -m "Update expedition detail UI v4.2"
git push origin main
```


## v4.3 PC/iOSレイアウト安定化

- PC版の司令室・帰投チェックをダッシュボード化し、横幅が広い画面でもカード配置が崩れにくいように調整。
- 艦隊カードの余白、ボタン、遠征選択、補正表示を再整理し、iOS風の白基調カードUIへ寄せました。
- スマホ版は「帰投チェック → 艦隊カード → 司令室サマリー」の順で確認しやすい表示順に調整。
- タブバー、下部ナビ、ライト/ダークテーマのコントラストを調整。


## v4.4 ダークモード視認性・設定タブ整理

- ダークモードで沈んで見えやすかったタブ、テーマ切替、カード内テキスト、補助文のコントラストを再調整。
- 設定タブの先頭に「設定メニュー」を追加し、アカウント同期・PWA・通知・報酬補正・通知診断・ログへワンタップで移動できるように整理。
- 設定タブを開いた時は詳細フォームを一度折りたたみ、必要な項目だけ開ける導線に変更。
- iOS設定アプリ風の角丸カード、アイコン、矢印付きメニューカードを追加。

## v4.5 ダークモードのタブ文字色修正

- ダークモードで非アクティブタブの文字が黒く沈んで見える問題を修正。
- デスクトップ上部タブ、スマホ下部タブ、ライト/ダーク切替の文字色をそれぞれ直接指定し、子要素のspan/small/bにも上書きが効くように調整。
- 非アクティブ、ホバー、アクティブ、フォーカス時のコントラストを整理し、黒背景でも読みやすいナビゲーションに変更。
