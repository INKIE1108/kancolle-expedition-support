# 艦これ遠征サポート v4.2

遠征タイマー、遠征検索、資源記録、通知をまとめて扱うPWAです。

## v4.2の変更点

- 遠征詳細の「編成条件・編成例」をカード化
- 各遠征の編成文字列からパターン別の編成条件と編成例を表示
- 43: ミ船団護衛(二号船団) は、護衛空母ルート / 軽空母ルートを明示
- ダークモードで文字が黒く沈む問題を追加修正
- モバイル下タブ、クイックプリセット、艦隊カード、遠征詳細、入力欄のコントラストを改善

## 更新手順

既存リポジトリに中身を上書きしてから、以下を実行してください。

```bash
npm install
npm run build
git status
git add .
git commit -m "Update expedition detail UI v4.2"
git push origin main
```
